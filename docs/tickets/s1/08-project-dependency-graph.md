# 08: Project dependency graph

**What to build:** The Project view gets a `graph` tile, second after `tickets`: every live, non-cancelled ticket in the project as a diamond node, edges from blocker to blocked, laid out left-to-right with dagre and drawn as our own SVG in house tokens — no graph library, no arrowheads, no opacity. A new read, `GET /api/projects/:id/graph`, returns `{nodes, edges}` in one query set: nodes carry `key`, `title`, `status`, `blocked_by` (open blockers, as everywhere), the **first non-empty line of the description** (never the full markdown), and for out-of-project ends an `external: {app, project}` naming where they live. Externals are one hop only — the direct other end of an edge that crosses the project boundary, never the chain beyond it. Trashed and `cancelled` tickets are omitted together with their edges, in the project or external: a Trashed thing is hidden everywhere, and a cancelled one blocks nothing and is waited on by nothing, so a chain A → C(cancelled) → B draws A and B with no edge — accurate, not a bug. Every other declared edge is drawn, satisfied ones included (ADR-0009: edges are durable facts).

**Drawing (DESIGN.md Colors, Components):** a node is a filled diamond in its status colour (draft/system/review; `done` filled mute); a **blocked** node is the same colour *hollow* with its title struck — the kanban's ◇ glyph, not a colour; an external node is mute with no status treatment (context, not subject). Key in mono beside the diamond, title beneath, clipped at ~26 characters (the popover has the whole thing). Edges are orthogonal steps (horizontal → vertical → horizontal, turning at the mid-gap between ranks, from node centres; dagre's own edge points are ignored): **dashed `--gf-mute` while the blocker is open, solid `--gf-dim` once satisfied**. The SVG is drawn at its natural size and the tile body scrolls both axes inside itself (max height ~480px); the page never scrolls sideways. Not a spanning tile. Header subtitle counts what is drawn (`12 tickets · 7 edges`); the legend is a mute mono line under the graph — *blocker → blocked · dashed while the blocker is open · ◇ blocked · mute is outside this project*. No tickets: the tile's empty copy. Tickets but no edges: still one rank of diamonds, legend reads *no dependencies yet — declare one from a ticket*.

**Interaction:** the whole node group is a link — click opens the Ticket view, `tab` reaches it. A popover appears after 120ms on hover and at once on focus: `--gf-raised`, 1px `--gf-rule`, positioned over the scroll container beside the node; it shows key, title, status chip, a *blocked by GF-a, GF-b* line when blocked, the description's first line as raw text, and `app / project` for an external. Touch has no hover: a tap opens. No polling — refetch on focus like the rest of the view. Reduced motion is the tokens' business (`--gf-fast` collapses to 0). Read-only: edges are declared on the Ticket view.

**Status:** implemented (2026-09-02)

**Decisions (grilled 2026-09-01):** all of the above; none is hard to reverse, so no ADR. `@dagrejs/dagre` (the maintained fork), not `dagre`. DESIGN.md Components' dependency graph entry amended — dashed means *the blocker is open*, reversing the rough-v5 mockup, which dashed the dead edge and painted `done` green. Work order: a throwaway renderer against fixture data first, judged by eye, then the read, the layout function and the tile; if the SVG disappoints, only the renderer is replaced (React Flow), the read and layout carry over. Cancelled hidden unconditionally — it does not follow the board's view option.
